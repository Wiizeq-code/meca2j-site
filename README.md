# Site vitrine MECA2J

Site vitrine du garage MECA2J, ZAC du Plateau, 54630 Flavigny-sur-Moselle.

Site statique en HTML et CSS, sans outil de construction.

## Fichiers

- `index.html` : la page d'accueil (services, le garage, contact)
- `style.css` : la mise en forme ; les couleurs se changent en haut du fichier
- `mentions-legales.html` : les mentions légales, obligatoires en France
- `assets/` : les images et l'icône

## Voir le site en local

Ouvrir `index.html` dans un navigateur, ou lancer :

```bash
npx serve .
```
